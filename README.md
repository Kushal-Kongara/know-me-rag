# Know Me RAG

An AI-powered portfolio knowledge assistant that answers questions about my experience, projects, skills, hackathons, and work using Retrieval-Augmented Generation.

## What this project teaches

- Document chunking
- Embeddings
- Vector search
- Retrieval-Augmented Generation
- LLM-powered answers
- Supabase pgvector
- Next.js API routes

## Goal

Build a simple RAG system from scratch and understand how knowledge sources, embeddings, vector databases, retrieval, and LLMs work together.
